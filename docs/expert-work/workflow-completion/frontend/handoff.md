# 研发与分析任务深化：界面交接

## 信息结构与主操作

沿用 React 19 工作台、既有浅色内容区与侧栏，不引入新组件依赖。新增导航“我的行动”。

- 研发详情：保留需求和叙述方案；增加可编辑跨系统实施计划（目标、可行性、缺口、风险、每仓影响/允许路径/验证/回退/前置系统/既有测试修改授权）、逐资源审批、重试和逐系统交付证据。结构化计划保存归一每行列表，方案未保存时不允许从该详情批准。
- 分析详情：增加决策目标、决策问题、约束和假设；指标 JSON 编辑收起为高级选项，提供维度对齐、同比比较与算术情景示例；增加各数据源审批、来源/质量/快照/结论证据、重试。未保存说明或计划时不允许批准。
- 行动建议：负责人可配置员工、期限、复测指标、基线/目标/方向及固定日期范围，展开维度筛选；支持真实指标复测、建议转研发和反馈历史。
- 我的行动：只请求本人行动和可审批资源；待审批区只展示本资源方案。员工可以提交结果，不因此获得分析报告或原数据读取入口。按未完成、逾期、全部筛选；通知可标记已读。
- 数据源连接：HTTPS 接口可配置同源下一页链接、分页上限和有限重试；显示最近连接检查状态。

## 加载、空数据和错误

新增模块显示加载与就地错误；请求失败保留表单值，不以成功提示替代真实 API。任务流程审批可重新加载。我的行动区提供刷新、无待办和无筛选结果状态。服务非 JSON 错误响应显示可理解的重试提示。操作处理中禁用提交。已结束行动不显示反馈入口；完成或不采纳要求结果依据。具体审批/修改/复测权限以服务端返回 flags 和校验为准。

## 代码位置

- `frontend/src/capabilities.tsx`：结构化方案、说明、审批、恢复和证据展示。
- `frontend/src/actions.tsx`：建议卡片、配置、反馈、复测、转研发、审批待办及通知。
- `frontend/src/main.tsx`、`intelligence.tsx`：工作台入口与详情集成。
- `frontend/src/session.tsx`：非 JSON 服务错误反馈。
- `frontend/src/style.css`：既有主题下的详情、分组、表单及窄窗口布局。
